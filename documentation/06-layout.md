# Layout Configuration

## Overview

The Leads module was customized using a hospitality-specific layout designed to capture all information required for hotel reservations, event enquiries, and corporate accommodation requests.

The default Zoho CRM layout was modified to better reflect the reservation process followed by LuxeStay Hotels.

## Configuration

The custom layout includes dedicated sections for:

- Guest Information
- Reservation Details
- Event Details
- Corporate Booking Information
- Guest Preferences
- Address Information

The layout organizes related information into logical sections, making it easier for reservation staff to complete records while improving data quality.

## Business Value

The customized layout:

- Improves data organization.
- Reduces unnecessary scrolling.
- Simplifies reservation processing.
- Provides a consistent data entry experience.
- Supports multiple hospitality booking scenarios.
