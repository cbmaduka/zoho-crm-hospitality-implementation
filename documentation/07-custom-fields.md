# Custom Fields

## Overview

Several hospitality-specific fields were added to the Leads module to capture information that is not available in the default Zoho CRM configuration.

These fields support hotel reservations, event planning, corporate accommodation, and guest preference management.

## Custom Fields

Examples include:

- Booking Type
- Room Type
- Number of Guests
- Check-in Date
- Check-out Date
- Event Type
- Event Date
- Corporate Company
- Airport Pickup Required
- Meal Preference
- Special Requests

## Business Value

The custom fields allow reservation agents to capture complete guest information while supporting operational planning and personalized customer service.
