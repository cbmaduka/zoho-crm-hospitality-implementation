# Layout Rules

## Overview

Layout Rules were configured to dynamically display fields based on the selected booking type.

This reduces unnecessary data entry while ensuring reservation staff only complete fields relevant to each booking.

## Implemented Rules

Examples include:

- Wedding bookings display wedding planning fields.
- Corporate bookings display company information.
- Airport pickup requests display transportation fields.
- Event bookings display event planning information.

## Business Value

Using Layout Rules:

- Simplifies the user interface.
- Reduces user errors.
- Improves data quality.
- Provides a better reservation workflow.
